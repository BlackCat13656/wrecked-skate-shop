# wrecked-skate-shop

> 🚧 Work in progress. Features are being added regularly.

## Description

Online skate shop built with vanilla JavaScript: a product catalog loaded
from JSON and a shopping cart saved in localStorage. Stock limits and
order tracking are coming next.

## Features

- [x] Product catalog loaded from my own `products.json` (48 products)
- [x] Cart with add, remove, clear and quantity controls
- [x] Cart saved in localStorage
- [ ] Search, category filter, and sort by price
- [ ] Stock limits in the cart
- [ ] Checkout form with validation
- [ ] Order tracking page

## Tech Used

- HTML, CSS and vanilla JavaScript (fetch, async/await, classes, localStorage)
- Font Awesome for icons

## Credits & What I Changed

This project started from the **Comfy House** e-commerce tutorial by
[John Smilga](https://github.com/john-smilga) (Coding Addict) and is being
turned into an original skateshop project.

### From the tutorial

- The cart logic and its `Products`, `UI` and `Storage` class structure
- The cart panel layout and the idea of saving the cart in localStorage

### What I built myself

- New branding: custom logo, color palette and skate shop theme
- Own product catalog (`products.json`) with 48 products, brands, types and
  stock, replacing the Contentful setup
