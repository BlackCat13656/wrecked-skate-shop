### From the tutorial

- Basic project structure and the idea of a cart saved in localStorage

### What I built myself

- Complete redesign: new theme, branding, layout, and styling
- Own product catalog (`products.json`) replacing the Contentful setup
- Search, category filter, and sort by price
- Stock limits in the cart
- Order tracking page
- Checkout form with validation
- Code split into modules
